Privacy policy

This draft describes the current local-first prototype. It is not ready for a public launch: the operator, contact details, hosting arrangements, legal basis, and jurisdiction still need to be supplied and reviewed.

What stays on your device

Tasks, topics, task links, work windows, session history, settings, saved resources, uploaded thumbnails, and reflections are stored locally. The standalone dashboard uses browser local storage. The extension uses Chrome extension storage. These are separate stores and do not sync with each other, another browser, or another device.

Optional activity recording

Recording is off by default. If you turn it on in the extension, Chrome asks for the optional tabs and idle permissions. Chrome may describe the tabs permission as access to browsing history. BrowserBuddy uses it to sample the domain of the foreground tab only when the browser is focused and active, the tab is not incognito, the domain is on your approved list, and a task’s planned work window is open. It stores the domain, approximate start and end times, and the associated task. It does not store page titles or full URLs as activity.

Activity is approximate. Sampling and browser sleep can miss or limit intervals. During a session, activity is associated only with that session’s task while its window is active. Otherwise it is associated with the selected task when possible; ambiguous overlapping windows are skipped. A next-day check-in is shown only when a recorded domain overlaps a planned task window for at least five minutes. You can skip it.

Site blocking and page checks

When you start a strict session with selected sites, Chrome asks for access to those domains. BrowserBuddy uses declarative rules to redirect matching top-level navigations to a local interruption page. The attempted URL is carried in that page’s address so that you can choose to continue; it is not added to activity history. Chrome and other browser software may keep their own history according to their settings.

If you choose the page-menu title check, the title and tab identifier are held temporarily in extension session memory for that check. The title is removed when you dismiss the check using its button or when the browser session ends. Closing the check tab another way may leave it in session memory until restart. The keyword comparison is local and is not AI.

Retention and control

Activity older than seven days, and sessions and reflections older than 90 days, are removed when BrowserBuddy next runs. Tasks and saved resources remain until deleted. You can download local data, delete recorded activity, or delete all BrowserBuddy data from Settings. Uninstalling the extension generally removes its local storage; browser and operating-system backups are outside the app’s control. You can revoke optional permissions in your browser’s extension settings.

Network requests and third parties

This version has no account, analytics, cloud AI, or application server that receives your tasks or activity. When a standalone dashboard is hosted, the hosting provider can receive normal web request information such as an IP address and access logs; hosting practices must be documented before launch. If you open a saved link or task link, the destination site has its own privacy practices and may show ads or recommendations. BrowserBuddy does not fetch video metadata.

Before launch

Operator and privacy contact: to be supplied. Relevant rights, legal basis, hosting-provider details, and any future sharing or cloud processing require a jurisdiction-specific review. This draft must be updated if the product’s data practices change.
