# BrowserBuddy concept pack

This is a design and planning pack, not a website or browser extension. The screens are static mockups with illustrative data.

## Files

- `BrowserBuddy-concept.pdf`: the three selected mockups and a concise product and implementation overview.
- `IMPLEMENTATION_PLAN.md`: feature specifications, privacy considerations, technical approach, milestones, and open decisions.
- `01-focus-dashboard.png`: intention and next-day reflection prompt.
- `02-interruption.png`: a task-specific distraction interruption.
- `03-focus-library.png`: an example learning-video library.
- `mascot.png`: the original Buddy character.

The prior website files were archived separately as `browserbuddy-website-archive.zip`, then removed from the working directory. No live service is included in this concept pack.

## Important video constraint

A future YouTube embed may show ads and recommendations, and its player cannot be modified to remove them. If the goal is no ads anywhere, a different properly licensed video source is needed. The implementation plan includes the details and source links.
